# Modern Login Page UI

A clean and responsive login interface built using HTML, CSS, and JavaScript.

## Objective
To design a modern login page interface with proper alignment and interactive authentication functionality.

## Features
- Email Input Field
- Password Input Field
- Login Button
- Create Account Option
- LocalStorage Authentication
- Responsive Layout
- Glassmorphism UI Design
- Animated Gradient Background

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Functionality
Users can:
- Create a new account
- Login using saved credentials
- Store account details using localStorage
- Experience responsive modern UI design
